# Calculator Pro (Calculator-X)

A simple, responsive web-based calculator UI built with HTML, CSS, and vanilla JavaScript.

## Overview

This repository contains a single-page calculator app (index.html) with a clean, mobile-friendly UI and support for basic arithmetic operations.

## Features

- Addition, subtraction, multiplication, and division
- Percentage, toggle sign (+/-), clear (AC), and delete (backspace)
- Decimal support
- Keyboard support (numbers, operators, Enter for equals, Backspace, Escape)
- Responsive design for small screens

## Usage

1. Open `index.html` in a web browser (double-click or serve with a static file server).
2. Click the buttons or use your keyboard to perform calculations.

For development, you can run a local static server (for example with Python):

```bash
# Python 3
python -m http.server 8000
# then open http://localhost:8000
```
